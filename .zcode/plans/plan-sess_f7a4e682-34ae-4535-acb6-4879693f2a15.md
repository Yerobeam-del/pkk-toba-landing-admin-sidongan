## Tujuan
Merombak halaman Manajemen SIEDA di Admin Panel:
1. **Hilangkan semua emoji** → ganti dengan icon SVG (mengikuti gaya halaman admin lain)
2. **Ikuti pola tabel + pagination standar project** → pakai partial bersama `admin/partials/table.blade.php` (pagination custom "Menampilkan X-Y dari Z data" + tombol Previous/Next, seperti halaman user-management)
3. **Hilangkan fitur Recycle Bin / Restore** (soft-delete `active=0` khas SIEDA): filter status, tombol Restore, kolom/teks recycle bin
4. **Tambah tombol "Hapus Semua Data"** untuk menghapus seluruh data SIEDA di database (pola konfirmasi Toast.confirm seperti fitur "Pembersihan Data" di sidongan-data)

## Perubahan

### 1. `routes/web.php` (~baris 349-355)
- Hapus route `POST /module/{module}/{id}/restore` (fitur restore dihapus)
- Tambah route `POST /module/{module}/delete-all` → `SiedaDataController@deleteAll`
- Update komentar grup route (tidak lagi "recycle bin")

### 2. `app/Http/Controllers/Admin/SiedaDataController.php`
- `index()`: statistik disederhanakan — hanya `total` + `aktif` per modul (hapus hitungan recycle bin); pass `$totalAktif` untuk kartu statistik
- `showModule()`: hapus parameter/filter `status` (aktif/terhapus); semua record ditampilkan; tambah eager-load relasi per modul (key `with` di config MODULES: `kepalaKeluarga`, `kelompokDasawisma`, `dusun`) supaya `data_get` di partial tabel berfungsi
- Hapus method `restore()`
- Tambah method `deleteAll(Request, module)`: validasi `confirm => required|accepted`, hitung record, `$model::query()->delete()` (hard delete) dalam `DB::beginTransaction()`, log warning, flash `success` berisi jumlah data terhapus
- Update docblock controller (tidak ada lagi soft-delete/recycle bin)

### 3. `resources/views/admin/sieda-data/index.blade.php` (rewrite)
- Semua emoji di kartu Quick Guide (👁️ 🗑️ ⚠️ ↩️) diganti icon SVG
- Kartu statistik: 2 kartu (Total Record Keseluruhan + Data Aktif di SIEDA) dengan icon SVG, gaya seperti user-management
- Tabel daftar modul: kolom **Modul | Total Data | Aksi** (hapus kolom Aktif/Recycle Bin)
- Quick Guide: 3 kartu dengan icon SVG (Lihat Data / Hapus Data / Hapus Semua Data) — kartu Recycle Bin & Restore dihapus
- Teks referensi "Recycle Bin" dihapus dari semua copy

### 4. `resources/views/admin/sieda-data/module.blade.php` (rewrite)
- Header: tombol kembali + judul + total record (hapus "di recycle bin")
- Form pencarian + dropdown "Tampilkan:" (25/50/100) gaya user-management (icon search di dalam input, tombol clear, chevron pada select)
- **Tabel via partial bersama** `@include('admin.partials.table')`:
  - `data` = `$items` (paginator → pagination standar otomatis, query string `search`/`per_page` tetap dipertahankan via `withQueryString`)
  - `columns` per modul (definisi di view, pola user-management) memakai `type => callback` untuk sel yang diformat: NIK/No.KK/ID (style code), Nama, Jenis Kelamin, TTL, Kepala Keluarga & Dasawisma (relasi), Status Ibu (badge Hamil/Melahirkan/Nifas), Tahun Config, dan kolom **Status** (badge "Aktif"/"Terhapus" dengan icon SVG)
  - `actions => []` + `rowActions` custom (karena primary key berbeda-beda: `nik`, `no_kk`, `id`):
    - Tombol **Detail** (icon mata) → route `admin.sieda-data.show`
    - Tombol **Hapus** (icon tempat sampah) → `confirmDeleteItem('{id}', '{nama}')` dari partial + form tersembunyi `delete-form-{id}` (id dikutip string di JS agar NIK 16 digit tidak kehilangan presisi)
  - `emptyIcon` = 'database', pesan kosong per modul
- **Section "Hapus Semua Data"** (danger zone, gaya sidongan-data cleanup): kartu merah dengan icon SVG + form POST ke `admin.sieda-data.delete-all` berisi `confirm=1` tersembunyi, `data-title`/`data-message`, dan JS `Toast.confirm` (pola `.cleanup-form` di sidongan-data) sebelum submit
- Semua emoji (↩️ 🗑️ ⚠️) dihapus; blok `<style>` lama yang tidak terpakai dibersihkan

### 5. `resources/views/admin/sieda-data/show.blade.php`
- Tombol **Restore** dihapus
- Badge status: "✓ Aktif"/"✗ Terhapus (Recycle Bin)" → badge SVG proper "Aktif"/"Terhapus" (tanpa kata Recycle Bin)
- Emoji di tombol Hapus Permanen (🗑️) dan teks konfirmasi (⚠️) → icon SVG
- Bersihkan style yang tidak terpakai (`.btn-success-outline`, `.btn-warning-outline`, `.badge-terhapus` disesuaikan)

## Verifikasi
- `php -l` pada controller
- `php artisan route:list` untuk memastikan route baru terdaftar & route restore hilang
- `php artisan view:cache` untuk memastikan semua Blade template ter-kompilasi tanpa error sintaks
- Cek visual halaman via server lokal (browser) jika memungkinkan

## Catatan
- Data tetap dibaca langsung dari database SIEDA (`sieda` connection) seperti sekarang — hanya tampilan/logika UI yang diubah
- "Hapus Semua Data" bersifat per-modul (menghapus seluruh record di tabel modul tsb. di database SIEDA) dengan konfirmasi ganda (Toast.confirm), tidak ada route global lintas-modul demi keamanan
